# ☕ Java Practice

Welcome to my Java Practice repository!

This repository documents my journey of learning and improving my Java programming skills. It contains practical exercises, examples, and small projects covering Java fundamentals and advanced concepts.

My goal is to build a strong foundation in Java and prepare myself for backend development with Spring Boot.

## 🎯 Learning Objectives

- Understand Java fundamentals and Object-Oriented Programming.
- Improve problem-solving and logical thinking.
- Learn how to write clean, reusable, and maintainable code.
- Understand how Java works behind the scenes.
- Prepare for professional backend development.

- Variables and Data Types
- Operators
- Conditional Statements (`if`, `else`, `switch`)

- Methods and Parameters
- Arrays and Strings

- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Static and Final Keywords
- Enums

### 3. Java Collections Framework

- ArrayList
- LinkedList
- HashSet
- HashMap
- Iterator
- List, Set, and Map
- Comparable and Comparator

### 4. Java Generics

- Generic Classes
- Generic Methods
- Bounded Type Parameters
- Multiple Type Parameters
- Wildcards
- Generic Interfaces

### 5. Exception Handling

- Try and Catch
- Finally
- Throw and Throws
- Custom Exceptions
- Checked and Unchecked Exceptions

### 6. Advanced Java

- Lambda Expressions
- Stream API
- Functional Interfaces
- Multithreading
- File Handling

### 7. Design Patterns

- Singleton Pattern
- Factory Pattern
